**역할: 서비스 기획**

- 문제 정의
- 설문 조사
- 앱 프로토타입 기획
- 비즈니스 모델 설계

RE:PLAY는 장애 청년이 취업 전에 안전하게 연습하고, 작은 실제 업무부터 경험하며, 그 결과를 자신의 직무 역량으로 증명할 수 있도록 설계한 단계별 취업 성장 플랫폼입니다.

“장애인이 일을 할 수 없는 것이 아니라, 실수하고 다시 시도하며 경험을 쌓을 수 있는 구조가 부족한 것은 아닐까?”라는 뇌병변 지적 장애인 팀장님의 질문에서 시작된 프로젝트입니다.

## 문제는 사람이 아니라, 다시 해볼 수 없는 구조

기존 장애인 취업 서비스는 장애등급과 완성된 직무를 기준으로 사람을 분류·매칭하는 경우가 많습니다. 하지만 같은 장애 유형에서도 개인별로 수행 가능한 업무와 필요한 작업 조건은 다릅니다.

하나의 직무 전체를 수행하기 어렵다는 이유로 그 안에서 수행할 수 있는 개별 작업까지 모두 제외되는 구조에 문제를 느꼈습니다.

따라서 문제를 “어떤 직무에 이 사람을 맞출 것인가”에서 “이 사람이 현재 어떤 조건에서 어떤 Task부터 수행할 수 있는가”로 재정의했습니다.

## 설문 조사

**19~30세 장애 청년 32명**을 대상으로 온라인 실태조사를 실시했습니다.

주요 조사 결과:

- 면접에서 말실수에 대한 두려움: **71.9%**
- 질문을 이해하지 못할 가능성에 대한 두려움: **59.4%**
- 개인 역량에 맞는 맞춤형 업무 선호: **68.8%**

이 결과를 바탕으로 사용자에게 필요한 것이 단순한 채용정보 제공보다 안전한 사전 연습, 사람과의 점진적인 상호작용, 작은 실제 업무 경험, 경험을 역량으로 증명하는 방법이라고 판단했습니다.

## 하나의 취업 대신 4단계 성장 로드맵

RE:PLAY는 사용자가 곧바로 일반 취업시장에 진입하도록 요구하지 않고 **AI 면접 연습 → 대학생 멘토 → Micro-task → R-Score·AI Portfolio**의 4단계 성장 구조를 설계했습니다.

### 1단계 — AI 면접 연습

사람과의 대면이 심리적으로 부담스러운 초기 단계에서 AI 가상 면접관과 반복적으로 자기소개, 면접 질문, 직장 내 상황 등을 연습하도록 설계했습니다.

시간과 장소에 구애받지 않고 반복할 수 있으며, 실수에 대한 부담 없이 기본적인 발화와 질문·응답 패턴을 익히는 것이 목적입니다.

서비스 기술 설계안에서는 LLM API를 이용해 시나리오 기반 대화를 생성하고 사용자 발화의 명확성·적절성·개선 포인트를 분석해 피드백하는 구조를 제안했습니다. 

### 2단계 — 대학생 멘토 면접 연습

AI와의 반복 연습에 적응한 뒤 실제 대학생 멘토와 화상으로 면접·스몰토크·직장 상황을 연습하는 단계입니다.

AI가 제공하기 어려운 표정, 제스처, 눈맞춤, 실제 사람과의 정서적 교류 등 비언어적 피드백을 경험하도록 설계했습니다. **AI → 실제 사람**으로 상호작용의 난도를 단계적으로 높이는 구조입니다.

### 3단계 — 직무가 아니라 Micro-task로 매칭

기존 장애인 채용은 사무보조, 청소, 데이터 라벨링처럼 완성된 직무 단위로 매칭되는 경우가 많습니다. RE:PLAY는 이를 더 작은 **Micro-task** 단위로 분해합니다.

예를 들어 우편물 분류는 부서별 분류와 부서 전달로, 데이터 라벨링은 이미지 객체 태깅과 텍스트 감정 분류로 나눕니다.

각 Micro-task에는 다음과 같은 작업 조건을 정의합니다.

- 글자 인식 가능
- 앉은 자세 가능
- 이동 가능 여부
- 보행 / 휠체어
- 시각 인식
- 마우스 / 터치 조작
- 반복 업무 선호
- 소음 민감도

따라서 장애등급이 아니라 **개인의 역량과 작업 조건**을 기준으로 Task를 매칭하는 구조를 기획했습니다.

### 4단계 — R-Score·AI Portfolio

Micro-task 수행 경험을 기업이 이해할 수 있는 성실성·역량 지표와 구조화된 포트폴리오로 전환하는 단계를 설계했습니다.

## 작은 업무를 점진적인 경력으로

사용자가 처음부터 정규직 수준의 업무를 수행할 필요가 없도록 성장 경로를 설계했습니다.

- 1개월차: 이미지 라벨링 / 일 1시간 → 소일거리 수준
- 3개월차: 라벨링 + 데이터 입력 / 일 3시간 → 단기 아르바이트 수준
- 6개월차: 데이터 입력 + 문서 분류 + 재고 확인 / 일 6시간 → 정규직 전환 검토

이렇게 **작은 성공 경험부터 쌓으며 업무 범위와 난도를 점진적으로 높이는 것**을 중점으로 삼았습니다.

## R-Score

Task 수행 데이터를 종합해 **R-Score**라는 성실성·역량 종합 지표와 AI Portfolio로 변환하는 구조를 설계했습니다.

R-Score에 반영하도록 기획한 항목:

- Task 완수율
- 결과 정확도
- 작업 속도
- 꾸준함 / 연속 수행일수
- Mentor Feedback

Task 특성에 따라 지표의 가중치를 다르게 적용하는 구조도 기획했습니다.


## AI Portfolio

R-Score와 Task 수행 데이터를 단순 숫자로 보여주는 것만으로는 기업이 사용자의 실제 업무 역량을 이해하기 어렵다고 판단했습니다.

수행한 Task, 정확도, 완수율, 지속성, Mentor Feedback, R-Score 변화를 기반으로 기업이 확인할 수 있는 구조화된 **AI Portfolio**를 생성하는 방향을 설계했습니다.

## 대학·기업·공공을 데이터로 연결

RE:PLAY는 단순 B2C 취업 앱이 아니라 **대학·기업·공공기관**을 연결하는 서비스 모델로 기획했습니다.

### 대학

장애학생지원센터를 대상으로 맞춤형 직무 교육과 커리어 관리 솔루션을 제공하는 구조입니다.

### 기업

데이터 라벨링·문서 분류·단순 입력 등의 디지털 Micro-task를 장애인 Talent Pool에 의뢰하고, Task 수행 결과를 확인한 뒤 채용으로 전환할 수 있는 구조입니다.

### 공공기관 / 지자체

취업지원 패키지와 연계하고 장애 유형별 Task 수행 및 고용 유지 데이터를 향후 정책 분석에 활용할 수 있는 구조입니다.

## 기업 입장에서 왜 필요한가

사회적 가치만 강조하지 않고 기업의 실제 문제도 함께 정의했습니다.

기업 Value:

- 정규 채용 전 Micro-task Trial
- 실제 수행 데이터 기반 인재 검증
- 장애인 의무고용 리스크 관리
- 디지털 Task outsourcing
- ESG 장애인 고용 성과

즉 **Micro-task Trial → 수행 데이터 → R-Score / Portfolio → 채용 검토**라는 채용 프로세스를 제안했습니다.

## 비즈니스 모델

대학·기업·공공기관별로 대학 솔루션 구독, 기업 인재 매칭, Micro-task 중개, B2G 라이선스·교육, 기업 ESG·장애인 고용 연계 서비스의 수익 구조를 설계했습니다.

발표자료의 TAM/SAM/SOM, 3개년 매출, 채용 건수는 사업계획상 추정값이며 실제 매출·계약·채용 성과가 아닙니다.

## 수상

**2026 제5회 장애·비장애 대학생 창업경진대회 우수상**

## 배운 점

장애인을 하나의 집단으로 정의하는 대신 당사자 조사를 통해 면접 불안과 맞춤형 업무에 대한 실제 니즈를 확인했습니다. 이후 완성된 직무 중심의 기존 매칭 방식을 개인의 역량과 작업 조건을 중심으로 한 Micro-task 방식으로 재설계하고, 사용자뿐 아니라 대학·기업·공공기관의 이해관계를 함께 분석했습니다.

이를 통해 **사용자 조사 → 문제 재정의 → Customer Journey → 서비스 구조 → 이해관계자 Value → Business Model**로 이어지는 서비스 기획 과정을 경험했습니다.
